# Rustorage 官网实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建一个 `website/` 静态目录，公网可挂域名访问，单页展示 Rustorage 的亮点与设计。

**Architecture:** 零构建静态站。`index.html` 是唯一页面，所有文案带 `data-i18n` 键，
两份文案树在 `assets/i18n.js`，`assets/app.js` 负责应用与交互，`assets/style.css`
承载全部视觉。**不用 ES module**（`file://` 下会被 CORS 拦），一律经典 `<script>`。

**Tech Stack:** 原生 HTML + CSS + JS。无 npm、无构建、无 CDN、无外部字体、无位图。

**前置规格：** `docs/superpowers/specs/2026-10-10-website-design.md`（已提交 `e4f2be4`）

---

## 与规格的一处执行约定

**本计划不逐字抄录双语文案。** 这是个内容型产物，文案就是代码——把 §5 的每一段
中英文都抄进计划再抄进 `i18n.js`，等于写两遍。所以计划给出的是**结构与键名**：
每节要哪些 key、什么层次、图形怎么画、类名清单、验证命令；**具体措辞在
Task 2 写 `i18n.js` 时落到最终形态**，内容范围以规格 §5 为准。
这是本计划唯一偏离「No Placeholders」的地方，明写在这里。

- [ ] **Step 1: 写 `check.sh`（护栏先立，此步必然失败）**

四条检查，全部用 `grep` / `sed`，不依赖 node：

**键的对齐靠 `i18n.js` 的书写格式**：`zh: {` / `en: {` 顶格两空格，
每行一个 `"flat.dotted.key": "值",`，缩进四空格。不嵌套对象——
扁平键才能让下面的 `awk` 切片可靠。这一条是本文件对 `i18n.js` 的**格式契约**。

```bash
#!/usr/bin/env bash
# 官网的本地自检护栏。不是流水线——随时手跑。
# 用法：bash website/check.sh
set -uo pipefail

cd "$(dirname "$0")" || exit 1
fail=0
note() { printf '  \033[31m✗\033[0m %s\n' "$1"; fail=1; }
warn() { printf '  \033[33m!\033[0m %s\n' "$1"; }
ok()   { printf '  \033[32m✓\033[0m %s\n' "$1"; }

echo "website 自检"

# 1) 没有外部请求：src=/href= 里不允许出现 http(s)://，仓库与文档的页面链接走白名单
outside=$(grep -nE '(src|href)="https?://' index.html 404.html assets/*.css assets/*.js 2>/dev/null \
  | grep -vE '(href|src)="https?://(github\.com/yyyCode/Rustorage|yyycode\.github\.io)' || true)
if [ -n "$outside" ]; then
  printf '%s\n' "$outside"
  note "出现了白名单之外的外部引用"
else
  ok "没有外部资源引用"
fi

# 2) 没有内联样式
if grep -nE 'style=' index.html 404.html 2>/dev/null; then
  note "HTML 里有内联 style="
elif grep -nE '\.style\.[a-zA-Z]' assets/*.js 2>/dev/null; then
  note "JS 里在写 .style. 属性"
else
  ok "没有内联样式"
fi

# 3) 双语键对齐：zh 与 en 的键集合必须完全相同
slice() { awk -v L="$1" '$0 == "  " L ": {" {f=1; next} /^  \},$/ {f=0} f' assets/i18n.js; }
zh=$(slice zh | grep -oE '^    "[^"]+"' | tr -d ' "' | sort)
en=$(slice en | grep -oE '^    "[^"]+"' | tr -d ' "' | sort)
if [ -z "$zh" ] || [ -z "$en" ]; then
  note "i18n.js 切片为空——检查 zh: { / en: { 的写法是否被改过"
else
  d=$(diff <(printf '%s\n' "$zh") <(printf '%s\n' "$en") || true)
  if [ -n "$d" ]; then printf '%s\n' "$d"; note "zh 与 en 的键不一致"; else ok "zh / en 键一致（$(printf '%s\n' "$zh" | wc -l | tr -d ' ') 个）"; fi
fi

# 4) HTML 用到的键两棵树里都有；树里的死键只提醒不拦
html_keys=$(grep -ohE 'data-i18n="[^"]+"' index.html 404.html 2>/dev/null \
  | sed 's/data-i18n="//;s/"//' | sort -u)
if [ -z "$html_keys" ]; then
  note "HTML 里没有任何 data-i18n"
else
  miss=0
  for k in $html_keys; do
    printf '%s\n' "$en" | grep -qx "$k" || { note "i18n.js 里没有键：$k"; miss=1; }
  done
  [ "$miss" = 0 ] && ok "HTML 用到的 $(printf '%s\n' "$html_keys" | wc -l | tr -d ' ') 个键都在"
  dead=$(comm -13 <(printf '%s\n' "$html_keys") <(printf '%s\n' "$en") || true)
  [ -n "$dead" ] && warn "树里没被 HTML 用到的键（可能是 JS 动态写入）：$(printf '%s' "$dead" | tr '\n' ' ')"
fi

if [ "$fail" = 0 ]; then echo "WEBSITE: OK"; else echo "WEBSITE: FAILED"; exit 1; fi
```

## Task 2: 双语机制

**Files:**
- Modify: `website/assets/i18n.js`
- Modify: `website/assets/app.js`

- [ ] **Step 1: 写完整的 `i18n.js`**

键名按区块分命名空间：`nav.*` / `hero.*` / `what.*` / `design.*` /
`diagrams.*` / `bench.*` / `scope.*` / `roadmap.*` / `footer.*` / `meta.*`。
内容范围照规格 §5，**中英两份同时写**（不写一份再翻译，措辞会拧）。

支持两种形态的值：
- 纯字符串 → 写 `textContent`；
- 需要内嵌标记（如 `<code>`）→ 用 `html` 后缀的键名，写 `innerHTML`。

- [ ] **Step 2: 写 `app.js` 的 `applyLang()`**

```js
function detect() {
  var saved = null;
  try { saved = localStorage.getItem("rustorage-lang"); } catch (e) {}
  if (saved && LANGS.indexOf(saved) >= 0) return saved;
  return /^zh\b/i.test(navigator.language || "") ? "zh" : "en";
}

function applyLang(lang) {
  var tree = I18N[lang];
  if (!tree) return;
  var nodes = document.querySelectorAll("[data-i18n]");
  for (var i = 0; i < nodes.length; i++) {
    var key = nodes[i].getAttribute("data-i18n");
    var val = tree[key];
    if (val === undefined) { console.warn("[i18n] 缺键: " + key); continue; }
    if (/Html$/.test(key)) nodes[i].innerHTML = val;
    else nodes[i].textContent = val;
  }
  document.documentElement.lang = lang === "zh" ? "zh-CN" : "en";
  if (tree["meta.title"]) document.title = tree["meta.title"];
  // 更新切换按钮的 aria-pressed 与两侧标签的选中态
}
```
