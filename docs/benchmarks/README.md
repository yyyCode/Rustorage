# 性能基准

每个子系统一份，各自独立成目录：方法、结果、局限分文件，原始输出原样存档在 `raw/`。

| 基准 | 测什么 | 目录 |
|---|---|---|
| IO 模式 | 读写路径四个 `IoModes` 机制的开销（新旧模式对比） | [io-modes/](io-modes/) |

## 约定

- **原始输出不复述、不美化**：跑出来什么样就存什么样，文件名带日期与轮次
  （`raw/YYYY-MM-DD-run-X.txt`）。结论从原始输出里推，不反过来。
- **数字必须与运行环境一起记**：机器、系统、规模参数、profile——离开这些，
  倍数就没有意义。
- **每个主测配一个阴性对照**：对照位不证明什么更快，它证明**这次测量没有在量别的
  东西**。没有对照位的加速数字，不足以作为证据。
- **另有 `局限` 一节**：写明哪些东西**没**测到（例如本机 `sync_dir` 是 no-op，
  fsync 那条线是平的）。这一节和结论同等重要。
